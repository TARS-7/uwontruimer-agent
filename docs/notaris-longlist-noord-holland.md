## Top 8 — waar eerst benaderen

1. **RijksBredius Netwerk Notarissen (Bussum)** — enige met hard bevestigd EPN-lidmaatschap én expliciet "executele/boedelafwikkeling als executeur". Grootste kans op regelmatig lege woningen. Contactpersoon op naam: mr. Dave Volmer.
2. **Stouthart & Hilber (Den Helder)** — noemt letterlijk "boedelafwikkeling", op naam bekende erfrecht-specialist (Natascha Stouthart-Hilber), klein/persoonlijk → makkelijk de beslisser bereiken.
3. **Abma Schreurs (Purmerend + Amsterdam/Hoorn/Volendam)** — middelgroot, meerdere vestigingen, "complexe nalatenschappen". Eén ingang, groot volume.
4. **Smith Boeser van Grafhorst (Haarlem)** — profileert nadrukkelijk op nalatenschappen in een grote stad met veel oudere woningbezitters.
5. **Erkamp Boot Willemsen (Alkmaar)** — 7 notarissen, dekt Alkmaar + Heerhugowaard → grote spreiding via één relatie.
6. **Notarishuis IJmond (IJmuiden)** — dekt hele Velsen/IJmond-regio, duidelijke estate-planning-praktijk, weinig concurrentie.
7. **Meijer Notarissen (Amsterdam)** — sterke estate-planning + verklaring-van-erfrecht praktijk in koopkrachtig grachtengebied.
8. **Waterland Notariaat (Purmerend)** — nadrukkelijk gespecialiseerd, apart familierecht-mailadres = directe boedel-ingang.

## Nog te verifiëren / vervolgstappen
- **NOVEX-executeurs op naam** per kantoor nalopen via novex-executeur.nl/novex-leden en register-executeur.nl/register/noord-holland.
- EPN-lidmaatschap Actor en Zaannotarissen 1-op-1 in EPN-register bevestigen.
- Ontbrekende telefoonnummers/e-mails aanvullen bij benadering.
- Heerhugowaard/Beverwijk: geen duidelijk erfrecht-kantoor gevonden (Erkamp Boot Willemsen dekt Heerhugowaard).
