# Onboarding-stappenplan: een notariskantoor live krijgen

_Van eerste "ja" tot een werkend account in het portaal. De techniek staat al klaar; dit is de
volgorde._

## Fase A — Benadering (commercieel)

1. **Mail + A4** naar de boedelbehandelaar (teksten: `notaris-benadering-rijksbredius.md`,
   `notaris-a4-aansprakelijkheid.md`). Bijlage: het `notaris-informatiepakket.pdf`.
2. **Opvolgtelefoon** na 4–5 werkdagen → kennismaking of 15-min portaaldemo (script:
   `notaris-pilot-draaiboek.md`).
3. Doel van dit gesprek: één proefdossier, geen "samenwerking".

## Fase B — Account aanmaken (technisch — in het interne dashboard)

_Alles gebeurt op `app.uwontruimer.nl` als interne medewerker (rol ADMIN/MEDEWERKER)._

1. Ga naar **`/organisaties`** → knop **"Nieuwe organisatie"**.
   - Naam: bijv. "RijksBredius Netwerk Notarissen"
   - Type: **Notaris**
2. Open de zojuist aangemaakte organisatie → knop **"Uitnodigen"**.
   - Vul het **e-mailadres van de notaris/boedelbehandelaar** in.
   - Dit stuurt een uitnodiging (Clerk-invite met rol **EXTERN** + koppeling aan deze organisatie).
3. De notaris ontvangt de mail, kiest een wachtwoord, en landt na inloggen automatisch op
   **`/portaal`** (rol EXTERN → portaal).
   - Werkt de koppeling niet meteen? De self-healing pagina **`/koppelen`** koppelt het account
     alsnog op e-mailadres.
4. Uitnodiging niet aangekomen? Op de organisatiepagina staat **"Opnieuw versturen"**.

## Fase C — Eerste dossier draaien

1. Notaris (of jij namens hem) start via **"Erfgenaam uitnodigen"** → erfgenaam vult zelf gegevens
   in (geheimhouding-schoon).
2. Objecten inventariseren → waardevolle stukken stromen naar Takaros → veilinghuis.
3. Ontruiming uitvoeren → **opleveringsbewijs** wordt beschikbaar zodra afgerond.
4. Levert de **inboedelinventarisatie-PDF** + **opleveringsbewijs-PDF** op voor het notarisdossier.

## Fase D — Nazorg & opschalen

1. Na een vlekkeloos dossier: vraag een citeerbare referentie.
2. Herhaal Fase A–C voor de volgende kantoren in het cluster (Het Gooi: RijksBredius → Horst & van
   de Graaff → Van Hengstum & Stolp).
3. Na 3 referentiedossiers: advertorial Vakblad PE Notariaat + EPN/NOVEX-event.
